Рабочая папка - каталог на компьютере, где лежат файлы, с которыми работаем

Индекс - черновик следующего коммита

Коммит - сохраненные версии проекта

Git - программа для добавления в облако кода, файла и тд

GitHub - веб-приложение для работы с файлом

git diff - показывает, что изменили, но еще не подготовили к сохранению

git diff --staged - показывает, что точно войдет в следующий коммит



\## Использованные команды



git status — показывает текущее состояние репозитория (какие файлы изменены, какие готовы к сохранению, а какие еще не отслеживаются).

git diff — показывает изменения в коде, которые еще не были добавлены в индекс (подготовлены к сохранению).

git diff --staged — показывает изменения, которые уже добавлены в индекс с помощью git add и войдут в следующий коммит.



\## Ветки



Ветка - это указатель на определенный коммит, который позволяет вести разработку параллельно от основной линии кода.

При новом коммите ветка автоматически передвигается вперед, указывая на самое последнее сделанное сохранение.

Слияние - это процесс объединения изменений из одной ветки в другую, собирающий параллельную работу воедино.

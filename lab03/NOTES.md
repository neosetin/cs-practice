git log — показывает историю коммитов

git show — показывает детали конкретного коммита

git diff — сравнивает разные версии между собой

log -S"def" — нашёл коммиты, в которых впервые появилось или исчезло слово "def".

blame — показал построчно, кто и в каком коммите написал каждую строку кода в файле.

git restore — сбрасывает мои текущие изменения и возвращает файл к состоянию последнего коммита. Если бы у меня были важные незакоммиченные правки, эта команда бы их просто стерла безвозвратно.

git restore --source=... — позволяет вытащить версию файла из любого старого коммита историии закинуть её в рабочую папку, чтобы посмотреть или вернуть старый код.

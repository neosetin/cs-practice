git log — показывает историю коммитов

git show — показывает детали конкретного коммита

git diff — сравнивает разные версии между собой

log -S"def" — нашёл коммиты, в которых впервые появилось или исчезло слово "def".

blame — показал построчно, кто и в каком коммите написал каждую строку кода в файле.
